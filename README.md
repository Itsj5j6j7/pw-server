# pw-server

Minecraft ↔ Discord tooling for the Propwash FPV community server:

- [`propwash-bridge/`](propwash-bridge): server-side Fabric mod that reports server status, records and `/link` codes.
- [`bot/`](bot): Discord bot and the HTTP API the mod reports to.

Both run on the same machine as the Minecraft servers. Each folder's README explains how to build, configure and run it.
